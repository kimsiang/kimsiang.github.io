## Development

The site is static HTML generated by a small Python script — edit the sources in `content/`, then rebuild:

```bash
pip install beautifulsoup4          # once
python3 tools/build.py              # regenerates index.html and every sub-page
```

| Edit this | To change |
|---|---|
| `content/home.html` | Home page (every string has an English `.en` and Chinese `.zh` version) |
| `content/pages/*.html` | Research, People, Teaching, Talks, Posters, Gallery, PI profile, About Muons chapters |
| `content/news/<slug>.html` + `content/news.json` | News posts (add an entry to `news.json`, newest first) |
| `content/publications-extra.json` | Papers INSPIRE doesn't list |
| `content/members.json` | Member sub-pages `people/<slug>.html` — background, awards (`awards`: [year, English, 中文]), ORCID / INSPIRE / Google Scholar IDs |
| `assets/media/` | Images used in pages and news (WebP, `-sm` = thumbnail) |

Refresh the publication list from INSPIRE-HEP (author record [1114795](https://inspirehep.net/authors/1114795)):

```bash
python3 tools/update_publications.py && python3 tools/build.py
```

Refresh each member's paper list (their INSPIRE record + PI papers matching their name; add a control number to `exclude` to drop a misattribution):

```bash
python3 tools/update_members.py && python3 tools/build.py
```

### “Ask the group” search bar

The home-page ask-bar answers questions from the group's own papers and pages. Retrieval (BM25) runs entirely in the visitor's browser over `assets/data/ask-index.json`, so it needs no server and works inside mainland China. Rebuild the index whenever papers, pages, news or members change:

```bash
python3 tools/build_ask_index.py            # fetches abstracts from INSPIRE (cached in content/abstracts.json)
python3 tools/build_ask_index.py --offline  # reuse cached abstracts
python3 tools/build.py
```

Out of the box the answer is *extractive* — the best-matching sentences, each cited back to its source. To add a written LLM synthesis on top, deploy `tools/ask-worker.example.js` as a Cloudflare Worker (or any endpoint with the same JSON contract) and set `window.MUON_ASK_ENDPOINT = 'https://…'` before `ask.js` loads. The page sends the question plus the retrieved passages; the model is told to answer from those passages only and cite them as `[n]`.

The 3D hero (a simulated cosmic-muon tracker) lives in `src/hero.js` and is bundled with Three.js into `assets/js/hero.bundle.js`:

```bash
npm install
npm run build
```

Fonts (Space Grotesk, Inter, JetBrains Mono) and all images are self-hosted so the site loads quickly inside mainland China.
